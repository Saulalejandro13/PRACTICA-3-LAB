Principales Elementos del Desarrollo Web

El desarrollo web se compone principalmente de tres tecnologías: HTML para la estructura, CSS para el diseño y JavaScript para el comportamiento.

Estructura (HTML) Estilo (CSS) Comportamiento (JavaScript)
<div>
<div>Contenido</div>
Permite crear divisiones o secciones dentro de una página web para organizar otros elementos. 		color
color: blue;
Permite modificar el color del texto de un elemento. 		onclick
onclick="miFuncion()"
Ejecuta una acción de JavaScript cuando el usuario hace clic sobre un elemento.
<p>
<p>Este es un párrafo</p>
Se utiliza para crear párrafos de texto dentro de una página web. 		font-size
font-size: 20px;
Permite modificar el tamaño de la letra de un elemento. 		addEventListener()
boton.addEventListener("click", funcion);
Permite detectar eventos realizados por el usuario, como clics, movimientos del mouse o pulsaciones del teclado.
<a>
<a href="pagina.html">Enlace</a>
Permite crear enlaces hacia otras páginas, documentos o sitios web. 		margin
margin: 20px;
Controla el espacio exterior que existe alrededor de un elemento. 		console.log()
console.log("Hola");
Permite mostrar información en la consola del navegador. Es muy utilizada para comprobar valores y detectar errores.
<img>
<img src="imagen.jpg" alt="Imagen">
Se utiliza para insertar imágenes dentro de una página web. 		padding
padding: 15px;
Controla el espacio interior entre el contenido y el borde de un elemento. 		Variables
let nombre = "Juan";
Las variables permiten almacenar datos que pueden utilizarse durante la ejecución de un programa.
<form>
<form>...</form>
Permite crear formularios para obtener información del usuario, como nombres, correos o contraseñas. 		border
border: 2px solid black;
Permite agregar y modificar el borde alrededor de un elemento. 		function
function saludo() { alert("Hola"); }
Permite agrupar instrucciones que pueden ejecutarse cuando sean necesarias.
<h1>
<h1>Título principal</h1>
Representa un encabezado o título principal dentro de un documento HTML. 		background-color
background-color: lightblue;
Permite modificar el color de fondo de un elemento. 		alert()
alert("Bienvenido");
Muestra una ventana emergente con un mensaje para el usuario.
<input>
<input type="text">
Permite crear campos donde el usuario puede introducir información. 		text-align
text-align: center;
Permite controlar la alineación del texto. 		if
if (edad >= 18) { ... }
Permite ejecutar instrucciones solamente cuando se cumple determinada condición.
